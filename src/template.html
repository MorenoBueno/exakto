Tipps

Strg+Z / Strg+Y macht Eingaben rückgängig bzw. stellt sie wieder her. F2 öffnet Graphen (◀▶ Trace, ▲▼ Funktion, +/− Zoom, Shift+Pfeile verschieben, 9 Fenster anpassen, 0 zurücksetzen, enter Analyse: Nullstellen, Minimum/Maximum, Schnittpunkte, y-Achsenabschnitt; auf dem Touchscreen ziehen, zoomen mit zwei Fingern, Tippen = Trace). F3 öffnet Elektrotechnik mit SI-Präfixen.

Mehrfach belegte Tasten wechseln bei wiederholtem Drücken: ln→log, sin→sin⁻¹, !→nCr→nPr, eˣ→10ˣ, π→e, x→y→z→t→a→b→c→d.

Ein ⚠ hinter einem Integral bedeutet: Konvergenz nicht gesichert (Wert unzuverlässig). Rechnungen, die länger als etwa 6 Sekunden dauern, werden mit „TIMEOUT“ abgebrochen.

Ergebnis exakt oder dezimal: ◀▶≈. Ein Operator als erste Eingabe rechnet mit dem letzten Ergebnis. ↑ holt frühere Eingaben zurück. Variablen, Listen, Verlauf und Einstellungen bleiben im Browser gespeichert.

Zweitfunktionen (2nd): complex (a+bi rechnen, f(z), Polar), matrix (A–C bis 4×4: +, −, ×, det, Inverse, rref …), vector (2D/3D: ·, ×, Betrag, Winkel …), op (Pol, Rec, Primfaktoren, Teiler, Division mit Rest), set op (Mengen aus L1–L3: ∪ ∩ ∖ △).

How to use

Open and close with ? or F1; Esc closes as well.

Input is shown in textbook style: fractions, roots and exponents. Use the arrow keys to move through fractions and exponents. Press ▶ to leave an exponent.

Tips

Ctrl+Z / Ctrl+Y undo / redo. F2 opens graphs (◀▶ trace, ▲▼ function, +/− zoom, Shift+arrows pan, 9 fit window, 0 reset, enter analysis: zeros, minimum/maximum, intersections, y-intercept; on touch screens drag, pinch to zoom, tap = trace). F3 opens the electrical tools with SI prefixes.

Keys with several functions cycle when pressed repeatedly: ln→log, sin→sin⁻¹, !→nCr→nPr, eˣ→10ˣ, π→e, x→y→z→t→a→b→c→d.

A ⚠ after an integral means convergence is not guaranteed (value unreliable). Calculations taking longer than about 6 seconds are aborted with “TIMEOUT”.

Exact or decimal result: ◀▶≈. An operator as first input uses the last result. ↑ recalls earlier entries. Variables, lists, history and settings are kept in your browser.

Second functions (2nd): complex (a+bi arithmetic, f(z), polar), matrix (A–C up to 4×4: +, −, ×, det, inverse, rref …), vector (2D/3D: dot, cross, magnitude, angle …), op (Pol, Rec, prime factors, divisors, division with remainder), set op (sets from L1–L3: ∪ ∩ ∖ △).
