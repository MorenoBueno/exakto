# Sicherheit

Exakto läuft vollständig im Browser, es gibt keinen Server, keine Konten und keine Übertragung von Eingaben. Verlauf und Einstellungen liegen im `localStorage` deines Browsers und lassen sich über die Browser-Einstellungen löschen.

Eine Sicherheitslücke melden: bitte über **Security → Report a vulnerability** im GitHub-Repository (privat) statt in einem öffentlichen Issue.
